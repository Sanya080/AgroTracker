# AgroTracker

AgroTracker — це GUI-додаток на Python для управління фермерським господарством.

## Можливості

- облік полів;
- облік посівів;
- журнал польових робіт;
- продаж культури;
- розрахунок доходу, витрат і прибутку;
- аналітика по полях.

## Технології

- Python
- CustomTkinter
- JSON для збереження даних
